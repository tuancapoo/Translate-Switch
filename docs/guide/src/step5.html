Chỉnh trong app, xử lý lỗi

Mở overlay Translate, mục Cài đặt:

Provider

Gemini, Claude, ChatGPT, OpenRouter hoặc API chuẩn OpenAI. Đổi provider sẽ đặt lại model.

Model

Chọn model cho provider đang dùng. Mặc định gemini-3.5-flash-lite.

Nền box

Kéo thanh trượt chỉnh độ trong suốt, có ô xem trước. Bấm B để lưu.

Phím tắt

Giữ tổ hợp 2 đến 4 nút mới khoảng 1,5 giây để lưu.

Gặp lỗi thì sao

  • Chưa đặt api_key: điền key vào config.ini như bước 2
  • 503 / timeout: nhà cung cấp AI quá tải, thử lại sau ít phút
  • Chữ Việt hiện ô vuông: thiếu DejaVuSans.ttf trong config\translate
  • Couldn't resolve host: kiểm tra Wi-Fi, dùng mục Kiểm tra mạng
Lưu ý: bật Wi-Fi khi chạy CFW có rủi ro với tài khoản Nintendo, nên dùng emuMMC và chặn các domain của Nintendo. Ảnh chụp màn hình được gửi qua server dịch vụ tới nhà cung cấp AI bạn chọn.
