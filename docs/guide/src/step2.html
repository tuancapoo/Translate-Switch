BƯỚC 2 / 5CP-Translate

Điền API key vào config

Làm ngay trên máy tính, trước khi chép vào thẻ SD.

1

Vào aistudio.google.com/apikey, đăng nhập GoogleBấm Create API key (nên dùng Gemini, miễn phí) rồi copy keyNhớ test key với model gemini-3.5-flash-lite xem dùng được không (có thể nhờ AI test giúp)Test key không dùng được? Liên kết tài khoản ngân hàng (thẻ) rồi thử lại

2

Mở config\translate\config.ini bằng Notepad

3

Dán key vào dòng api_key= rồi lưu file

# url và token đã điền sẵn, không cần sửa url=https://translate-nx.netlify.app/api/translate token=... provider=gemini api_key=DÁN_KEY_CỦA_BẠN_VÀO_ĐÂY model=gemini-3.5-flash-lite
Không chia sẻ file config.ini hay API key cho người khác. Chỉ sửa sau dấu =, không thêm dấu cách hay dấu ngoặc.
