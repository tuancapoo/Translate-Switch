Chép vào thẻ SD

Chép nội dung (đã điền key) vào gốc thẻ SD của Switch.

1

Tắt Switch, rút thẻ SD cắm vào máy tính

2

Chép hai thư mục switch và config vào gốc thẻ SDNếu hỏi trùng thư mục, chọn Gộp (Merge), đừng thay thế

SD:\ (gốc thẻ nhớ) ├─ atmosphere\ ├─ switch\ │ └─ .overlays\ │ └─ translate.ovl ← overlay └─ config\ └─ translate\ ├─ config.ini ← đã có api_key ├─ DejaVuSans.ttf ← font tiếng Việt └─ DejaVu-LICENSE.txt
Đừng chép cả thư mục CP-Translate vào thẻ. Hai thư mục switch và config phải nằm ngay ở gốc thẻ SD.
Gốc thẻ SD = nơi có sẵn thư mục atmosphere3 / 5
